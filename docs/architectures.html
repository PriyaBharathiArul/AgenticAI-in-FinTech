What each architecture looks like

Three ways of answering the same finance question, in the order they were built. Same question in, three different paths to an answer — this is the actual shape each one takes.

1 / Baseline

One LLM call. No tools. Answers from memory alone.

Why it exists: the control group. Nothing here gets tool access — every failure it has is the baseline every other architecture is measured against.

2 / Single Agent

One LLM, all 7 tools, up to 10 rounds of think–call–observe.

Why it exists: tests whether tool access alone helps, before splitting the work up. Breaks down on questions needing several chained calls at once.

3 / Multi-Agent

Three narrow specialists in parallel, merged by an aggregator.

Why it exists: the team's first attempt chained specialists sequentially and errors compounded — a wrong ticker from one agent silently corrupted the next. Parallel + aggregate decouples them.
baseline → single agent → multi-agent, in the order each one was built to fix the last one's failure mode
