What each tool actually does

Every tool takes arguments the model chose, reaches for one data source, and hands back JSON the model reads as its next "observation." Solid green is the real/primary path; dashed gold is a fallback that fires when the primary path fails or is unavailable.

real / primary source fallback path guardrail / blocked

1 / get_tickers_by_sector(sector)

"Which companies are in this sector?" — a lookup, not a live-data question.

2 / get_price_performance(tickers, period)

"How has this stock moved?" — always changing, so it always has to be fetched live.

3 / get_company_overview(ticker)

"What's this company's P/E, EPS, market cap?" — fundamentals that shift every trading session.

4 / get_market_status()

"Is the market open right now?" — a question about the current moment, which the model has no concept of.

5 / get_top_gainers_losers()

"What's moving today across the whole market?" — no single stock to ask about, so a scrape instead of an API.

6 / get_news_sentiment(ticker, limit)

"How is the market feeling about this stock?" — real headlines, but a sentiment label with no real analysis behind it.

7 / query_local_db(sql)

The escape hatch — anything the other 6 fixed tools can't express as a question.
